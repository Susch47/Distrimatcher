# Distrimatcher – Brand

| File | Use |
|---|---|
| `logo.svg` / `logo.png` | Logo with wordmark and tagline, on light backgrounds |
| `logo-light-on-dark.svg` / `.png` | Logo on dark backgrounds (Abyss / Deep Teal) |
| `logo-mark.svg` / `.png` | App icon / favicon / small sizes |
| `logo-mark-on-dark.svg` | Icon on dark backgrounds |

**The mark:** a "D" whose outline is not closed. The coral dot in the gap is the missing share class that Distrimatcher finds. The sage check stands for confirmed coverage.

## Colours – "Ocean Serenity" + signal

| Name | Hex | Use |
|---|---|---|
| Abyss | `#01161E` | Text, dark surfaces |
| Deep Teal | `#124559` | Primary, "covered" |
| Mist Blue | `#598392` | Secondary, lines, icons |
| Sage | `#AEC3B0` | Context, accents |
| Foam | `#EFF6E0` | Backgrounds |
| Signal Coral | `#D0603F` | Gaps and calls to action only |

Deep Teal and Signal Coral were checked for colour-vision deficiency (ΔE ≥ 20). Chart values are always labelled.

## Typography
Montserrat Light (headings, body) and Semibold (emphasis). In a bank setting the house font, e.g. Verlag, can replace it 1:1.

The brochure source is `docs/brochure/brochure.html`. Build it with `node render.js` (PDF) and `node export-assets.js` (PNG graphics); both need Playwright.
