DISTRIMATCHER – Testpaket für Windows   (die App selbst ist auf Englisch)
=========================================================================

Start
  Ordner "Distrimatcher" öffnen und Distrimatcher.exe doppelklicken.
  (Windows SmartScreen kann warnen: "Weitere Informationen" -> "Trotzdem ausführen" – das Programm ist nicht signiert.)
  Die App startet leer. Alles läuft lokal; die Vertragsdaten verlassen den PC nicht.

User Journey
  1 · Agreements       Testdaten\demo_agreements.zip in das Upload-Feld ziehen.
                        -> 9 Verträge werden gelesen (einer ist ein Scan -> OCR). Spaltenköpfe anklicken = sortieren.
  2 · Overview          "Suggest from agreements" -> "Load selected" (öffentliche SEC-Daten, braucht Internet)
                        "Import file" -> Testdaten\Fondsliste_mit_Retro.csv
                        -> Wasserfall: Fund IDs -> ISINs -> in Verträgen gefunden -> abgedeckt -> Lücken.
                        Info-Button (i) = Handbuch (bearbeitbar).
  3 · Watchlist         Lücken prüfen: Confirm / Dismiss / Add to agreement / Open agreement.
  4 · Provider e-mail   Anbieter wählen -> vorformulierte E-Mail (EN/DE) -> "Download .eml" öffnet sich in Outlook.
  5 · Activity log      Protokoll aller Schritte; "Reset all data" = von vorne beginnen.

Daten
  %LOCALAPPDATA%\Distrimatcher  (Datenbank, PDFs, manual.md = Handbuch, Log). Ordner löschen = alles zurücksetzen.
